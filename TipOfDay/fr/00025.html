Exporter des préréglages

Saviez-vous qu'on peut exporter plusieurs préréglages dans un seul fichier xpreset ? Rangez-les dans un groupe, puis sélectionnez le groupe avant de cliquer sur le bouton d'export.

À l'import, un groupe contenant tous les préréglages est créé.

En prime, si vous avez des groupes dans des groupes, toute l'arborescence est exportée dans le fichier xpreset.
