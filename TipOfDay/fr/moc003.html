Ne mettre que les contours des visages dans les groupes Maison/Jardin/Tout

Beaucoup posent des effets sur des groupes « toute la maison », « tout le jardin », « tout le décor » ou similaires. On est tenté d'y mettre tous les modèles (pour que le groupe porte bien son nom). Mais le rendu peut alors manquer de finesse, surtout pour les décors à visages chantants, à plusieurs états, les décors combinés avec plusieurs modèles sur le même coroplaste, ou tout ce qui rend bizarrement quand tous les pixels s'allument ensemble.

La solution : ne mettre dans ces groupes que certains sous-modèles... pour un décor chantant, peut-être seulement les contours ; pour un « trio » ou un « quatuor », peut-être seulement le sous-modèle spinner, etc.

(En cas de difficulté, vérifiez toutes les zones surlignées en rouge.)
