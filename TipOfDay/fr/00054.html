Vérification de séquence : modèle dans plusieurs vues

Avez-vous déjà vu un avertissement comme celui-ci dans la vérification de séquence, en vous demandant ce qu'il signifie et comment le corriger ?

"WARN: Model Group 'Verticals' in preview 'Unassigned' contains model 'Verical Door' which is in preview 'Default'. This will cause the 'Verical Door' model to also appear in the 'Unassigned' preview."

J'ai deux aperçus... l'aperçu par défaut, le principal que je regarde, et un aperçu non assigné (que vous avez aussi), où je range les modèles que je ne veux pas afficher.

J'ai un modèle « Vertical Door » dans mon aperçu par défaut, donc je le vois... mais ce modèle est dans un groupe qui se trouve dans l'aperçu non assigné. Quand je regarde l'aperçu non assigné, je vois donc « Vertical Door »... Ici c'est sans conséquence et je peux l'ignorer... mais je pourrais aussi le corriger de deux façons :

  • déplacer le groupe « Verticals » dans l'aperçu par défaut... c'est sans doute la bonne solution ;
  • déplacer le modèle « Vertical Door » dans l'aperçu non assigné... mais je ne le verrais plus dans mon show... et ce n'est pas ce que je veux.

Ce n'est qu'un avertissement... il est parfois utile de faire apparaître un modèle dans plusieurs aperçus, et un groupe de modèles est un moyen simple d'y parvenir.
