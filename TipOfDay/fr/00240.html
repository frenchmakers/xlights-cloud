Rétablir après une annulation

Si vous annulez une modification puis changez d'avis, vous pouvez maintenant la rétablir. Utilisez Rétablir dans le menu Édition, ou son raccourci clavier.

Rétablir refait une à une les actions que vous venez d'annuler, exactement comme elles étaient. Il va de pair avec Annuler : vous pouvez faire des allers-retours pour comparer deux versions d'une modification.

Vous pouvez ainsi expérimenter l'esprit tranquille : annulez quelques étapes pour revoir l'état précédent, puis rétablissez pour revenir où vous en étiez.
