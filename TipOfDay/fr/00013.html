Organisation du dossier du show

Il existe de nombreuses façons d'organiser vos dossiers, mais certaines sont meilleures que d'autres. Tout dépend un peu de vos besoins. Je pars du principe que vous voulez séparer les années, et aussi les fêtes (même si ce n'est pas obligatoire, si les aperçus vous suffisent).

Je pars aussi du principe que vous travaillez dans votre dossier Documents sous Windows... cela varie selon le système, et ce n'est pas essentiel.

Mon dossier de Noël serait donc : C:\Users\<vous>\Documents\xLights\2022\Christmas

Et celui d'Halloween : C:\Users\<vous>\Documents\xLights\2022\Halloween

En gardant l'année hors du nom du dossier du show lui-même, on laisse xLights gérer les chemins quand on le déplace d'un ordinateur à l'autre.

Dans le dossier du show, je crée des dossiers pour les éléments clés :

  • Audio : toute ma musique, et aussi les vidéos dont j'utilise le son
  • Video : les vidéos utilisées dans les effets
  • Images : les fichiers image utilisés
  • Import\<fabricant>\<séquence> : tous mes imports... ainsi les images et autres fichiers qui en viennent restent bien dans le dossier du show et ne se perdent pas
  • Palettes : les palettes que j'enregistre
  • valuecurves : les courbes de valeur que j'exporte
  • Colorcurves : les courbes de couleur que j'exporte
  • Shaders : les shaders que je télécharge
  • DownloadedFaces : les images de visages que je télécharge

Vous pouvez garder ou non les dossiers « Backup » et « Render Cache » dans le dossier du show. Je les déplacerais sans hésiter ailleurs via les préférences si votre dossier du show est synchronisé dans le cloud ou se trouve sur un petit SSD. Ces deux dossiers peuvent devenir énormes avec le temps si vous ne les surveillez pas.

Personnellement, je laisse mes séquences directement dans le dossier du show. Certains préfèrent un dossier par séquence, ou un dossier unique pour les séquences. Dans ce cas, activez bien « Sauvegarder les sous-dossiers » dans les préférences, sinon vous n'aurez peut-être pas les sauvegardes attendues. Vous voudrez sans doute aussi ranger les fichiers utilisés par chaque séquence dans des sous-dossiers du dossier de cette séquence.
