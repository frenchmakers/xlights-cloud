Documenter votre show

Une bonne partie de ce que l'on notait autrefois dans des tableurs pour documenter son décor n'est plus forcément nécessaire avec xLights.

  • Le menu Outils/Export Models exporte toutes les données de vos modèles et contrôleurs dans un tableur Excel (.xlsx), pour les fois où vous voulez vraiment voir toute la configuration des contrôleurs et des modèles dans une simple liste.
  • Le menu Outils/Exporter les connexions des contrôleurs crée une liste de câblage avec tous vos contrôleurs et les modèles branchés sur chaque port.
  • Les champs de description des contrôleurs et des modèles permettent de noter des informations libres que vous ne mettriez pas autrement dans xLights.
  • Dans le visualiseur, un clic droit permet d'imprimer la configuration du contrôleur.
  • Le champ de connexion au contrôleur peut aussi servir, même si vous n'utilisez pas l'envoi vers les contrôleurs.

Si vous utilisez encore des tableurs, nous aimerions savoir quelles données supplémentaires vous notez hors de xLights, pour vous permettre de tout regrouper au même endroit.
