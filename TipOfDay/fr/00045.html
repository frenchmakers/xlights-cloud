Empaqueter une séquence

Pour partager une séquence, utilisez toujours Outils > Empaqueter la séquence : le paquet contiendra à coup sûr tous les fichiers sources nécessaires pour reproduire la séquence, où qu'ils se trouvent sur l'ordinateur.

Pour utiliser une telle séquence, quelques étapes clés garantissent qu'elle fonctionne bien, et continue de fonctionner une fois importée :

  • Soit vous importez la séquence directement depuis le fichier zip : tous les liens de fichiers sont parfaits, mais vos dossiers s'encombrent et il est difficile d'examiner la séquence importée.
  • Soit vous extrayez le fichier zip, mais :
    1. Extrayez le zip dans un sous-dossier de votre dossier du show.
    2. Basculez temporairement votre dossier du show vers le dossier d'extraction.
    3. Vérifiez que la disposition est bien celle depuis laquelle importer.
    4. Chargez la séquence.
    5. Faites le rendu de la séquence et lisez-la pour vérifier que tout est correct.
    6. Enregistrez la séquence : c'est absolument essentiel, car cela corrige tous les chemins de fichiers en vue de l'import.
    7. Revenez à votre dossier du show.
    8. Importez la séquence depuis le dossier d'extraction.

Pour un partage public, excluez le fichier audio pour des raisons de droits d'auteur : une option le permet. Profitez-en pour exclure aussi vos préréglages si vous le souhaitez.
