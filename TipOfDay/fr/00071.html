Per Model Default pour les groupes

Les groupes de modèles ont maintenant une option de disposition « Per Model Default » dans leurs propriétés.

Quand elle est réglée, tout effet posé sur le groupe avec le style de rendu Default est automatiquement rendu modèle par modèle, au lieu de s'étaler sur toute la grille du groupe. Vous la réglez une fois sur le groupe, et chaque effet Default de ce groupe suit.

Pratique quand un groupe est composé de décors identiques, comme une rangée de mini-sapins ou des arches assorties, et que vous voulez qu'un effet joue de la même façon sur chacun au lieu d'être étiré sur tous.
