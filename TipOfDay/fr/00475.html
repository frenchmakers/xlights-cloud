Modèle Tree horizontal

Le modèle Tree peut être disposé à l'horizontale, pas seulement en cône vertical habituel.

Choisissez l'option horizontale dans les réglages du modèle Tree : les brins vont de côté au lieu de monter vers une pointe. Un modèle sapin peut ainsi représenter des décors larges plutôt que hauts, avec le câblage et les réglages familiers du sapin.

Un moyen rapide de réutiliser le modèle sapin pour une autre forme sans rien construire sur mesure, ce qui simplifie la gestion de votre disposition.
