Couleurs d'étiquette des groupes de modèles

Vous pouvez attribuer une couleur d'étiquette à un groupe de modèles pour distinguer vos groupes d'un coup d'œil.

Réglez la couleur dans les propriétés du groupe, dans l'onglet Disposition. Le groupe ressort alors dans les listes où apparaissent vos groupes, pratique quand un show en compte des dizaines.

Choisissez un code qui vous parle, par exemple une couleur pour les groupes de toiture et une autre pour les sapins, et la navigation dans une disposition chargée devient bien plus simple.
