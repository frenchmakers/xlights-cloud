Choisir le décodeur vidéo matériel

Sous Windows, vous pouvez choisir le décodeur vidéo matériel utilisé par xLights pour lire les vidéos de l'effet Video. L'option se trouve dans les préférences, avec les autres réglages vidéo.

Chaque matériel graphique fonctionne mieux avec certains décodeurs : pouvoir en choisir un permet d'adapter xLights à votre machine. Si des vidéos saccadent ou ne se décodent pas avec une option, passer à une autre peut régler le problème.

Si vos vidéos se lisent déjà bien, inutile de changer quoi que ce soit, mais il est bon de savoir que ce choix existe quand un clip ou une carte graphique pose problème.
