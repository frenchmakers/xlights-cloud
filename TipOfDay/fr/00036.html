Vue du câblage

Câbler vos modèles exactement comme xLights les voit est essentiel pour que tout s'affiche correctement.

C'est le rôle de la vue du câblage. Faites un clic droit sur le modèle dans la disposition et choisissez « Vue du câblage » pour voir comment les pixels doivent être disposés.

Par défaut, la vue du câblage montre le modèle de dos. En effet, sur la plupart des décors en coroplaste, les pixels sont enfoncés par l'arrière : il est donc plus logique de les voir de dos. Pour passer à la vue de face, utilisez le menu du clic droit.

Pour enregistrer ou imprimer l'image, faites un clic droit dessus. Passez-la d'abord en noir sur blanc pour économiser l'encre.

Remarque : certains modèles n'ont pas de vue du câblage, par exemple les modèles DMX et les blocs de canaux.
