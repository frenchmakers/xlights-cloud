xScanner

Il faut parfois analyser votre réseau pour identifier les contrôleurs.

On utilisait autrefois des outils comme Advanced IP Scanner et Angry IP Scanner. Ils trouvent très bien les adresses IP des appareils du réseau, mais ne savent pas grand-chose de ces appareils.

C'est pourquoi nous avons créé xScanner, disponible dans le menu Outils.

xScanner analyse aussi votre réseau, mais au lieu de se limiter aux méthodes réseau génériques, il connaît les protocoles et technologies courants du hobby des illuminations. xScanner peut ainsi :

  • utiliser la configuration de xLights pour repérer les appareils probables et les chercher, même sur des réseaux distants ;
  • utiliser les protocoles de découverte des contrôleurs pour identifier les appareils locaux ;
  • utiliser sa connaissance de FPP pour parcourir la configuration des proxys FPP ;
  • relever des informations de configuration importantes sur les appareils trouvés, grâce à sa connaissance des contrôleurs.

Autre avantage : xScanner analyse tous les réseaux disponibles, pas un seul... même si vous avez plusieurs réseaux ou des appareils répartis sur plusieurs réseaux, il les trouvera sans doute en une seule analyse.
