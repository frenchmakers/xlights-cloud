Propriété Active des contrôleurs

Les contrôleurs ont une propriété Active qui peut prendre 3 valeurs :

  • Active : les contrôleurs actifs reçoivent toujours les données quand vous activez la sortie vers les lumières, lancez une séquence dans xSchedule ou lisez une séquence sur FPP.
  • Inactive : les contrôleurs inactifs ne reçoivent jamais de données. Très utile quand un contrôleur est temporairement débranché, car envoyer des données à un contrôleur absent peut provoquer des erreurs avec les contrôleurs USB, ou des ralentissements réguliers avec les contrôleurs Ethernet.
  • xLights only : ces contrôleurs reçoivent les données quand vous activez la sortie vers les lumières dans xLights, mais pas quand une séquence est lancée depuis xSchedule ou après envoi sur FPP. C'est utile pour les décors sur des contrôleurs pilotés par des paquets de synchronisation, ou locaux au lecteur du show.
