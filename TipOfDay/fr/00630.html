Envoi KiNet via FPP

Si vous pilotez des lumières en KiNet, xLights peut inclure les univers de sortie KiNet quand il envoie votre configuration de sorties vers un appareil FPP.

Configurez vos sorties KiNet normalement, puis utilisez FPP Connect pour envoyer la configuration. Les univers KiNet partent avec le reste, et le lecteur sait comment joindre ces projecteurs.

FPP peut ainsi servir de sortie pour le matériel KiNet de votre show, toutes vos définitions de canaux restant gérées au même endroit dans xLights.
