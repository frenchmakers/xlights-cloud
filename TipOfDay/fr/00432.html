Mode sombre sous Windows

Sous Windows, xLights peut afficher son interface en thème sombre, avec du texte clair sur fond sombre.

Il s'active dans les préférences. Si vous préférez l'interface claire habituelle, l'option « Désactiver le mode sombre » garde xLights en clair même quand Windows est réglé en sombre.

Une interface sombre fatigue moins les yeux pendant les longues séances de séquençage, surtout la nuit près de votre décor : essayez le réglage qui vous convient.
