Importer des sous-modèles d'une autre disposition

Dans la fenêtre des sous-modèles, vous pouvez importer des sous-modèles déjà définis dans une autre disposition. Ouvrez la fenêtre d'un modèle et choisissez l'option d'import de sous-modèles depuis un autre fichier de disposition.

Si vous avez soigneusement construit des sous-modèles sur un décor similaire dans un autre show, vous reprenez directement ces définitions au lieu de recréer chacune nœud par nœud.

Particulièrement utile quand vous réutilisez les mêmes décors physiques dans plusieurs shows : le travail fait une fois sur les sous-modèles vous suit dans chaque disposition.
