Statistiques de séquence

Parfois, on a juste besoin des chiffres : Outils > Exporter les effets fournit tout un lot de statistiques sur votre séquence, dont :

  • La liste complète, effet par effet, sous forme de tableau, avec :
    • l'heure de début
    • l'heure de fin
    • la durée
    • la description de l'effet, si vous en avez saisi une
    • le modèle concerné
    • les fichiers utilisés par l'effet
  • À la fin, un résumé de la séquence avec :
    • le nombre d'utilisations de chaque type d'effet
    • la durée totale d'utilisation de chaque type d'effet
    • la liste complète des fichiers dont dépend la séquence : images, vidéos, etc.
