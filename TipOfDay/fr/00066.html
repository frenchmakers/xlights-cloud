Script Lua : rendre et exporter un modèle en vidéo

Le script Lua intégré RenderExportModel (dans Outils > Exécuter des scripts) fait le rendu d'une ou plusieurs séquences et exporte un modèle en fichier vidéo, en une seule étape, sans ouvrir chaque séquence à la main.

Au lancement du script, vous choisissez :

  • le modèle à exporter ;
  • le format vidéo (voir ci-dessous) ;
  • les séquences à traiter ;
  • s'il faut forcer le rendu en haute définition.

Chaque séquence est ouverte, rendue, exportée dans un sous-dossier portant le nom du modèle, puis fermée automatiquement.

Formats vidéo disponibles

Choix de formatSortieRemarques
Compressed MP4.mp4H.264 : fichier le plus léger, bonne compatibilité
High Quality MP4.mp4HEVC : quasi sans perte, plus léger que le brut
Uncompressed AVI.aviRGB brut : fichier le plus lourd, sans perte de qualité
Lossless RGB MOV.movSans perte, alternative à l'AVI adaptée au Mac
ProRes 4444 MOV.mov4:4:4 quasi sans perte ; idéal pour le montage vidéo
HD ProRes MOV.movProRes 4444 mis à l'échelle en 1920×1080

Le script BatchRenderExportModel exporte le modèle choisi en Compressed MP4 pour chaque séquence sélectionnée.
