Superposer vos arches

Le modèle Arches a une option pour superposer ses arches. Au lieu de placer chaque arche côte à côte, vous pouvez les empiler pour qu'elles soient l'une devant l'autre dans l'aperçu.

Le réglage se trouve dans les propriétés du modèle Arches. La superposition convient quand vos arches réelles sont imbriquées ou concentriques plutôt qu'alignées en rangée dans le jardin.

Accorder ce réglage à la disposition physique de vos arches rend l'aperçu correct et aide les effets qui parcourent tout le modèle à se comporter comme prévu sur les vrais décors.
