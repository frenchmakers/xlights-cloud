Zoomer vers le curseur dans la disposition

Une préférence détermine si la vue Disposition zoome vers le centre de l'écran ou vers le curseur de la souris. Choisissez le comportement qui vous semble naturel dans les préférences (« Zoomer vers le curseur »).

Avec le zoom vers le curseur, vous pointez un modèle, zoomez, et le modèle reste sous le pointeur en grandissant. C'est le comportement de nombreux logiciels de cartes et de dessin.

Si vous travaillez sur de grandes dispositions et plongez souvent dans un coin pour ajuster un seul décor, ce réglage vous évite beaucoup de déplacements.
